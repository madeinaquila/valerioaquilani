# Valerio Aquilani, portfolio

UX/UI designer: progettazione di prodotti digitali, UX research e AI.

**Sito:** https://madeinaquila.github.io/valerioaquilani/

## Cosa trovi

- **Progetti**
  - ReStart, app per il recupero fisico dopo il trapianto (Figma)
  - TeleRoma 56 Sport, rebranding di una TV storica di Roma (Illustrator, After Effects)
  - Palazzo Fava, identità visiva e segnaletica per uno spazio espositivo di Bologna
  - Anche dati: progetti di analisi con SQL, Python, NumPy ed Excel
- **Percorso:** dal Liceo Artistico e dal lavoro come grafico all'Accademia di Belle Arti di Roma, fino al design di prodotti digitali.

I notebook Python e la presentazione del progetto SQL sono nella cartella [`files`](files).

## Com'è fatto

Sito statico in HTML, CSS e JavaScript, scritto a mano e pubblicato con GitHub Pages.

- Nessun framework e nessuna libreria esterna.
- Font ospitato nel sito (Archivo, licenza SIL Open Font License): nessuna richiesta a Google Fonts.
- Nessun cookie e nessun sistema di tracciamento.
- Accessibile da tastiera, con contrasti verificati e rispetto dell'impostazione "riduci movimento".
