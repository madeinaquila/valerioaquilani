# Valerio Aquilani, portfolio

Analisi dati e UX/UI design.

**Sito:** https://madeinaquila.github.io/valerioaquilani/

## Cosa trovi

- **Progetti:** casi studio raccontati con problema, metodo e risultato.
  - Sviluppo sostenibile in 195 Paesi (SQL, PostgreSQL)
  - LookBook, gestione di un catalogo di abiti second-hand (Python)
  - File Organizer, riordino di file e analisi delle immagini (Python, NumPy)
  - Spreco alimentare (Excel avanzato)
  - Owly, report per una piattaforma scolastica (Excel)
  - ReStart, app per il recupero fisico dopo il trapianto (Figma)
- **Competenze:** dati, design e sviluppo.
- **Percorso:** dal Graphic Design all'Accademia di Belle Arti di Roma all'analisi dei dati.

I notebook Python e la presentazione del progetto SQL sono nella cartella [`files`](files).

## Com'è fatto

Sito statico in HTML, CSS e JavaScript, scritto a mano e pubblicato con GitHub Pages.

- Nessun framework e nessuna libreria esterna.
- Font ospitati nel sito (Smooch Sans e Hanken Grotesk, licenza SIL Open Font License): nessuna richiesta a Google Fonts.
- Nessun cookie e nessun sistema di tracciamento.
- Accessibile da tastiera, con contrasti verificati e rispetto dell'impostazione "riduci movimento".
